# Abstract
The adsorption–extraction method is a promising technique for detecting pathogens in wastewater. This workflow consists of electronegative membrane filtration and mechanical disruption of the mem-brane using a homogenizer, followed by direct nucleic acid extraction and PCR detection. This method allowed to achieve a 50% SARS-CoV-2 RNA detection probability at 0.64 clinically con-firmed COVID-19 cases per 100,000 inhabitants. However, the adsorption–extraction method cannot be easily adopted, because it requires expensive equipment (i.e., a homogenizer) for the bead-beating step to efficiently extract viral nucleic acids from membrane filters. Here, we developed a method that replaces physical disruption with chemical membrane dissolution using acetone. This method com-pletes viral quantification within 6 hours without complicated procedures, providing timely wastewater data. The sensitivity of this method was assessed using municipal influent samples col-lected between May 19 and December 20, 2022 (n = 26). We found that the novel method is estimat-ed to be 2.75-fold less sensitive for SARS-CoV-2 detection than the conventional method. Despite this lower sensitivity, it is expected to enable SARS-CoV-2 RNA detection when only a few con-firmed COVID-19 cases per 100,000 inhabitants are reported. These findings suggest its practical util-ity, contributing to enhanced wastewater monitoring of infectious diseases.
